位置推定の方式

使い方

マップ・区間の指示・火災の通知に使う、位置の計算方法を選びます。①〜⑥ はいつも同時に計算しています。

  • ① 強い AP 2つを 8:2 で配分（今までの方法）　② ① を時系列でなめらかに
  • ③ 強い 2つの電波の差で間のどこかを出す　④ ③ を時系列で（Wi-Fi＋BLE で一番良い候補）
  • ⑤ Wi-Fi だけ、3つ目の AP まで使う　⑥ Wi-Fi と BLE をそれぞれ向いた計算で合わせる

選び方: 決まった地点（0m・50m…）に立ち、マップの作業者アイコン →「推定の比較」→「正しい位置」に今の位置を入れて「記録」。この表に方式ごとの誤差がたまるので、いちばん小さい方式を選んで「この方式を使う」。

ウォッチが RSSI（電波の強さの数値）を送るまでは、①〜⑥ はほぼ同じ値になります。

カメラ

使い方
  • 「映像を見る」を押すと、カメラが約 1 秒ごとに撮った画像が出ます（コマ送り）。映るまで最大 10 秒ほどかかります
  • 見ていない間、カメラは画像を送りません。10 分たつと自動で止まります（もう一度押せば続きが見られます）
  • 「カメラの設定」で名前・入口からの距離・受け取る/受け取らないを変えられます。BLE を兼ねるカメラの距離は「ESP32 AP」表の距離と同じ値になります
  • カメラを増やすときは firmware/esp32cam_uplink/README.md の「カメラごとの設定ファイル」

入場管理

使い方
  • ウォッチが登録済みの AP（AP位置設定・ESP32 AP）の電波を拾うと「入場中」、どれも拾えなくなると「退場」になります
  • 左が今の状態（入場中が上）、右が直近 30 件の入場・退場の記録です。5 秒ごとに更新されます
  • 名前は「ユーザー設定」でウォッチの装置 ID と結び付けたものが出ます

AP位置設定（現場の Wi-Fi AP）

使い方
  • AP を足す:「新規追加」→ MAC アドレス（AA:BB:CC:DD:EE:FF）と入口からの距離 [m] を入れる →「保存」。番号は自動で振られます
  • 直す: MAC や距離を書き換えて「保存」。消す: 行の「削除」
  • プリセット: 今の表を名前を付けて保存しておき、別の現場では「読み込み」→「保存」で切り替えられます
  • ESP32 で作ったビーコン・AP は、下の「ESP32 AP」表で設定します

ユーザー設定

使い方
  • ウォッチの装置 ID と、画面に出す名前を結び付けます。「新規追加」→ 名前と装置 ID を入れて「保存」
  • 結び付けていないウォッチは、マップや入場管理に装置 ID のまま出ます

ESP32 AP

使い方
  • ESP32（ビーコン・カメラ）は、電源を入れてインターネットにつながると自動でこの表に出ます
  • 入口からの距離 [m] を入れて「保存」すると位置推定に使われます。距離が空の行は使われません
  • 手で追加: 表の下の欄に MAC（BLE はシリアルに出る address=…）・表示名・距離・種類を入れて「追加」。インターネットにつながらない ESP32 用です。あとから本物が通信すると、その行に引き継がれます
  • 「使わない」にすると位置推定から外れます。「削除」しても、動いている ESP32 は次の通信でまた出てきます
  • 状態: 稼働中（90 秒以内に通信あり）/ 停止 / 手動登録（まだ通信が来ていない）
